# playlist-maker-android-RubanKirill
Учебный проект по созданию мобильного приложения


СПРИНТ-3
-
-Был создан главный экран приложения с 4 кнопками (Поиск, плейлисты, избранное, настройки).

-При нажатии на кнопки поиска и настроек происходит переход на соответствующие экраны. На оставшихся кнопка стоят заглушики Toast

-Дизайн удалось повторить полностью, всё как на макете из Figma

СПРИНТ-4
-
-Были созданы и свёрстаны экраны поиска и настроек

-Переход между экранами теперь через навигацию

СПРИНТ-5
-
-Проект переведен на Clean Architecture с разделением на слои Data, Domain и UI.

-Реализована эмуляция сетевых запросов с имитацией задержки ответа сервера.

-Создан экран со списком треков на Jetpack Compose с применением паттерна MVVM.

-Добавлено управление состоянием экрана через ViewModel и StateFlow (загрузка, результат, ошибка).

СПРИНТ-6
-
-Реализован автоматический поиск (debounce) с использованием Coroutines.

-Добавлена загрузка обложек треков с помощью библиотеки Coil

-Обновлена модель данных Track для поддержки уникальных идентификаторов и ссылок на изображения.

СПРИНТ-7
-
-Добавлен функционал по кнопке "Плейлисты".

-Приложение запускается и показывает экран с кнопкой FloatingActionButton.  
 
-При нажатии на кнопку появляется окно ModalBottomSheet. 

-При нажатии на экран за пределами ModalBottomSheet панель скрывается.  

СПРИНТ-8
-
-При переходе с главного экрана на экран "Поиск" отображается поисковая строка. При наборе символов в поисковой строке начинается поиск треков, соответствующих введённому запросу. В начале поиска отображается лоадер. При завершении поиска лоадер исчезает и на экране отображается список найденных треков или сообщение, если ничего не было найдено.

-При клике на трек происходит переход на экран детального описания трека. Экран детального описания трека помимо данных о треке имеет кнопки для добавления композиции в «Избранное» и в существующий плейлист.

-При переходе с главного экрана на экран "Плейлисты" отображаются список существующих плейлистов и кнопка для создания нового плейлиста. При нажатии на кнопку создания нового плейлиста осуществляется переход на экран создания нового плейлиста.

-Экран создания нового плейлиста имеет возможность задать имя и описание этого плейлиста.

-При переходе с главного экрана на экран "Избранное" отображается список всех треков, добавленных в «Избранное».

СПРИНТ-9 (находится в ветке СПРИНТ-8)
-
-Экран плейлиста открывается из списка плейлистов.

-Отображается название, описание и список треков в плейлисте.

-Навигация «Назад» работает корректно (возврат к списку плейлистов).


СПРИНТ-10
-
-В проект подключена библиотека Room для работы с базой данных.

-Созданы сущности TrackEntity и PlaylistEntity, настроены DAO для сохранения и чтения треков и плейлистов.

-Хранение плейлистов и треков переведено с моков на реальную базу данных Room.

-Реализовано сохранение истории поиска через DataStore.

-Создан экран "Избранное", на котором отображается список всех избранных треков с обложкой, названием, исполнителем и длительностью.

-Реализовано удаление трека из избранного по долгому нажатию.

-На экране деталей трека добавлена кнопка "Добавить в избранное" с переключением состояния.
