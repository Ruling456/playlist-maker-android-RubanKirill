# Playlist Maker (учебный проект)

Обучающее Android-приложение на языке Kotlin, созданное с применением современного инструментария Jetpack Compose.

## Текущий функционал

### Главное меню и переходы

- Стартовый экран приложения со всеми основными разделами.
- Полноценная навигация между модулями с помощью Navigation Compose.

### Модуль поиска

- Интуитивное поле ввода с подсказкой «Поиск».
- Интерактивная иконка поиска и кнопка мгновенного удаления текста.
- Динамический вывод найденных композиций в виде списка (`LazyColumn`).
- Фильтрация по локальной базе треков, работающая без учета регистра символов.

### Раздел настроек

- «Поделиться приложением» — вызывает стандартное системное диалоговое окно отправки ссылки.
- «Написать разработчикам» — запускает установленный почтовый клиент с автоматически заполненной темой и адресом.
- «Пользовательское соглашение» — перенаправляет пользователя на веб-страницу с документом в браузере.

## Как запустить

1. Откройте проект в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Запустите конфигурацию `app` на эмуляторе или устройстве.

Сборка из консоли (Windows PowerShell):

```powershell
./gradlew.bat assembleDebug
```
